นโยบายความเป็นส่วนตัว

หน้า "งานที่ได้ทำไปแล้วและติดตามคดี" ใน LINE · มีผลตั้งแต่วันที่ 8 พฤศจิกายน 2569

1. ผู้ดูแลข้อมูล

บริการนี้จัดทำและดูแลโดยพนักงานสอบสวน สถานีตำรวจภูธรบางใหญ่ ผู้ดูแลบัญชี LINE Official Account @282rvbmp (ต่อไปเรียกว่า "ผู้ให้บริการ") ติดต่อได้ทางแชตของบัญชี LINE ดังกล่าว

2. ข้อมูลที่เก็บ

  • รหัสผู้ใช้ LINE ในรูปที่แปลงแล้ว เมื่อท่านเปิดแท็บ "ติดตามคดีของคุณ" LINE จะส่งเครื่องหมายยืนยันตัวตน (ID token) มาให้ ผู้ให้บริการตรวจสอบกับ LINE แล้วเก็บเฉพาะค่าที่แปลงทางเดียว (hash) ของรหัสผู้ใช้ LINE ซึ่งย้อนกลับเป็นรหัสเดิมไม่ได้
  • คดีที่ท่านติดตามและเวลาที่เริ่มติดตาม เมื่อท่านใส่รหัสติดตามคดี
  • ผู้ให้บริการไม่เก็บชื่อที่แสดง รูปโปรไฟล์ อีเมล หรือเบอร์โทรศัพท์ของท่าน และหน้านี้ไม่อ่านข้อความแชตของท่าน
  • หากใส่รหัสผิด ระบบจะนับจำนวนครั้งไว้ชั่วคราวไม่เกิน 1 ชั่วโมง เพื่อป้องกันการเดารหัส

3. วัตถุประสงค์และฐานทางกฎหมาย

ใช้เพื่อแสดงความคืบหน้าโดยย่อของคดีที่ท่านเป็นผู้แจ้งความหรือผู้เกี่ยวข้อง ให้เฉพาะผู้ที่ได้รับรหัสติดตามคดีเท่านั้น โดยอาศัยความยินยอมของท่านเมื่อท่านใส่รหัสติดตามคดี และเพื่อการปฏิบัติหน้าที่ของพนักงานสอบสวนตามกฎหมาย ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

4. ข้อมูลที่แสดงต่อท่าน

เลขคดีและประเภทคดี วันที่รับแจ้งความ วันที่แจ้งความคืบหน้าแล้ว วันที่ส่งสำนวน (ถ้ามี) และสถานะคดีโดยย่อที่พนักงานสอบสวนระบุ ไม่แสดงชื่อบุคคล ชื่อเอกสาร หรือเนื้อหาในสำนวน แท็บ "งานที่ได้ทำไปแล้ว" แสดงเฉพาะตัวเลขรวม ไม่มีข้อมูลของบุคคลใด

5. การเปิดเผยและผู้ให้บริการภายนอก

  • LINE (LY Corporation) ใช้ยืนยันตัวตนเมื่อเปิดหน้านี้ใน LINE ตามนโยบายความเป็นส่วนตัวของ LINE
  • Google ข้อมูลตามข้อ 2 เก็บใน Google Sheets และประมวลผลด้วย Google Apps Script ภายใต้บัญชีของผู้ให้บริการ
  • GitHub ให้บริการโฮสต์หน้าเว็บนี้ และอาจบันทึกข้อมูลทางเทคนิค เช่น หมายเลข IP ตามนโยบายของ GitHub

ผู้ให้บริการเหล่านี้อาจเก็บข้อมูลไว้บนเซิร์ฟเวอร์นอกประเทศไทย ผู้ให้บริการไม่ขายหรือส่งต่อข้อมูลของท่านให้ผู้อื่น เว้นแต่กฎหมายกำหนด

6. ระยะเวลาเก็บรักษา

เก็บไว้จนกว่าท่านจะกด "เลิกติดตาม" ซึ่งจะลบการเชื่อมคดีนั้นทันที หรือจนกว่าผู้ให้บริการจะลบเมื่อคดีสิ้นสุดหรือยุติบริการ

7. คุกกี้และการเก็บในเครื่อง

หน้านี้ไม่ใช้คุกกี้ติดตามหรือเครื่องมือวิเคราะห์การใช้งาน แต่เก็บที่อยู่ของระบบไว้ชั่วคราวในเบราว์เซอร์ (sessionStorage) ระหว่างที่เปิดหน้าอยู่ ส่วนชุดเครื่องมือของ LINE (LIFF) อาจเก็บข้อมูลการเข้าสู่ระบบ LINE ไว้ในเบราว์เซอร์ตามนโยบายของ LINE

8. สิทธิของท่าน

ท่านมีสิทธิขอเข้าถึง ขอสำเนา ขอแก้ไข ขอลบ หรือถอนความยินยอม (กด "เลิกติดตาม") และร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล ติดต่อใช้สิทธิได้ทางแชตของบัญชี LINE ข้างต้น

9. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลง จะแจ้งไว้ที่หน้านี้พร้อมวันที่มีผล
